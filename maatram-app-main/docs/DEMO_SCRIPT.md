# 4-minute demo script

1. **Admin → Reports → Load demo data.** Dashboard instantly fills (open, overdue, per-coordinator workload, categories, trend).
2. **Admin → Rules.** Show "Scholarship → Coordinator A" rule + follow-up timings; click *Run follow-up check now*.
3. **Student rep → Log a Query** (WhatsApp, scholarship). Note the category suggestion and screenshot upload; submit in under a minute.
4. **Admin → All Queries.** New query appears (auto-assigned by rule, history shows *Auto-assignment*). Search by student, filter *Overdue*.
5. **Coordinator → Assigned Queries.** Open it, set *Waiting for Student* with a note.
6. **Student rep** gets a notification, replies in the app → status returns to *In Progress*.
7. **Coordinator → Resolved.** Student is notified (in-app + email/SMS/WhatsApp when configured).
8. **Admin → Notifications.** Show an escalation and the history timeline of an overdue demo query.
9. Close with the privacy note (`docs/MIGRATION_AND_PRIVACY_NOTE.md`).
